# Execute PRP Implementation

Implement a feature using the PRP file from the enhanced workflow system.

## PRP File: $ARGUMENTS

**Expected Input**: PRP file from `PRPs/active/` directory
**Process**: Complete implementation following PRP specifications
**Output**: Fully implemented feature with validation complete

## Execution Process

1. **Load PRP**
   - Read the specified PRP(product requirements prompt) file
   - Understand all context and requirements
   - Follow all instructions in the PRP and extend the research if needed
   - Ensure you have all needed context to implement the PRP fully
   - Do more web searches and codebase exploration as needed

2. **ULTRATHINK**
   - Think hard before you execute the plan. Create a comprehensive plan addressing all requirements.
   - Break down complex tasks into smaller, manageable steps using your todos tools.
   - Use the TodoWrite tool to create and track your implementation plan.
   - Identify implementation patterns from existing code to follow.

3. **Execute the plan**
   - Execute the PRP
   - Implement all the code

4. **Validate**
   - Run each validation command
   - Fix any failures
   - Re-run until all pass

5. **Complete**
   - Ensure all checklist items done
   - Run final validation suite
   - Report completion status
   - Read the PRP again to ensure you have implemented everything

6. **Backlog Update**
   - Move PRP from `PRPs/active/` to `PRPs/completed/`
   - Update `PRPs/backlog/backlog-manager.md` with completion status
   - Update success metrics and completion time
   - Document lessons learned for future PRPs

7. **Reference the PRP**
   - You can always reference the PRP again if needed
   - Keep completed PRPs for pattern reference

Note: If validation fails, use error patterns in PRP to fix and retry.
